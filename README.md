# 第一次用 Mac：写给 macOS 新手的入门教程

**从第一次打开 Mac，到能自己完成日常工作。**

这份中文教程写给第一次使用 Mac 的人。你不需要懂编程，也不需要先学终端。无论你刚从 Windows 换过来，还是第一次拥有电脑，都可以从第一章开始。

教程尽量使用 Mac 自带的功能。每章都有明确目标、操作步骤和小练习。遇到陌生词，可以随时打开[术语表](docs/glossary.md)。

**默认原则：非必要不登录 Apple 账户。确实需要时，只登录所需服务，尽量少开启同步。** Mac 本地用户账户与 Apple 账户是两回事。基础练习使用本地文稿和备份，iCloud 属于可选内容，具体登录范围见[第一章](docs/01-first-steps.md)。

## 现在就开始

第一次读，只做下面四项。每做完一项，就检查右栏的结果：

| 先做什么 | 从哪里开始 | 怎样算完成 |
| --- | --- | --- |
| 联网并认清入口 | [第一章](docs/01-first-steps.md)第 1–5 节，已经看见桌面可从第 2 节开始 | 能打开网页、找到系统设置，并锁屏后解锁 |
| 打开和退出一个应用 | [第二章](docs/02-desktop-and-apps.md)及章末练习 | 能打开文本编辑，关闭测试窗口，再退出应用 |
| 输入并修改文字 | [第三章](docs/03-keyboard-and-trackpad.md)第 1–6 节及小练习 | 能输入中英文，替换一个词，再撤销修改 |
| 保存第一份文稿 | [第四章](docs/04-finder-and-files.md)第 1–3 节 | 能在“文稿”中找到文件，重新打开，内容仍在 |

可以分几次完成，不必一次读完四章。接下来按章节继续，或跟着[七天练习计划](docs/learning-plan.md)完成一轮。标为“按需”的内容，等遇到相应需求时再读。目录中的时间只是参考，系统更新、数据迁移和备份等待另算。

如果你正被某个问题卡住，可以直接去[常见问题的查找表](docs/10-troubleshooting.md#按问题查找)。

## 如何读操作步骤

- “点按”是点击一次。
- “连按两下”是快速点击两次。
- “拖移”是按住项目，移动到目标位置后松开。
- 要求输入“Mac 入门练习”这样的名称时，只输入引号内的文字，保留名称中的空格。
- `Return` 是回车键，`Esc` 常用于取消。完整按键说明见[第三章](docs/03-keyboard-and-trackpad.md)。
- `系统设置 → 通用 → 软件更新` 表示依次进入这些页面。
- `⌘ C` 表示按住 Command，再按 C，然后一起松开。组合键需要同时按住，不能逐个敲击。
- 拷贝、粘贴、存储等应用内快捷键作用于当前应用。先点需要操作的文稿窗口或访达文件列表，再按快捷键。
- “文稿文件夹”指访达中的“文稿”位置，“文稿文件”指你创建的一份内容。保存步骤会分别说明文件名和目标文件夹。
- 每个小练习都可以用测试文件完成。涉及删除、磁盘或恢复的练习会明确说明注意事项。

## 适用范围

操作说明以简体中文界面、macOS Ventura 13 及之后的常见操作为主，并单独标注较新功能的版本要求。MacBook、iMac 和 Mac mini 都可阅读。触控板相关步骤需要内建或外接触控板。英文界面的常用名称列在术语表中。

官方资料核对日期：**2026-10-05**。本教程没有在每一种 Mac 和系统版本上逐项实机验证。找不到某个入口时，先在系统设置内搜索功能名，再参照[版本差异](docs/references.md)。公司或学校管理的 Mac，部分设置可能由管理员控制。

章节配图是说明常见操作概念的原创示意图，适用范围和绘制日期见[配图说明](assets/README.md)。实际外观、按钮位置和功能支持情况以自己的系统为准。
