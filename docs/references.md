# 版本差异与参考资料

[返回目录](../README.md)

## 本教程怎样核对

资料核对日期：**2026-10-05**。章节使用独立编写的解释和练习，功能入口与快捷键参照下列 Apple 官方资料。也对照了后文列出的公开教程，检查基础操作和讲解顺序是否完整。本教程没有在全部版本和全部硬件上逐项实机验证。

Apple 的在线手册有版本选择器。不带版本号的链接可能打开较新的版本，阅读时应切换到自己“关于本机”显示的版本。第三方应用的行为以其当前官方说明为准。

## 最需要留意的差异

| 你看到的现象 | 可能原因 | 如何继续 |
| --- | --- | --- |
| 教程说“系统设置”，电脑上是“系统偏好设置” | macOS Monterey 12 或更早的界面命名 | 用对应版本的官方手册查入口 |
| 找不到与旧教程相同的启动台图标 | 应用浏览入口随版本变化 | 用聚焦，或访达“应用程序”文件夹 |
| 绿色按钮的文字和布局不同 | 系统版本、应用支持情况不同 | 先手动拖移并调整大小 |
| 拖到边缘没有新版平铺提示 | 较早版本、相关开关关闭，或窗口不支持 | 另行检查 Sequoia 15 起的增强功能，也可继续手动并排 |
| “文本输入”与“文字输入”，“隐私与安全性”与“隐私与安全”不一致 | 不同资料或界面的译名 | 在系统设置中搜索“输入法”或权限名称 |
| 调度中心手势需要三指或四指 | 手势配置与版本不同 | 看“触控板”页面的当前演示 |
| 截图格式或录制窗口选项不同 | 较新系统与硬件加入了额外选项 | 以截图工具栏实际提供的选项为准 |
| 找不到“密码”独立应用 | 该应用从 Sequoia 15 起提供 | Ventura 13、Sonoma 14 可在系统设置或 Safari 设置中查看密码 |
| iCloud 文件菜单没有“保留下载” | 系统版本或当前文件状态不同 | 使用实际提供的下载选项，出门前打开检查所需文件 |
| 旧款 Intel Mac 应用提示 Rosetta 或无法运行 | 芯片与系统兼容性不同 | 优先获取 Apple 芯片或通用版本，查看当前 Rosetta 支持范围 |
| 某些设置无法修改 | 权限限制或组织设备管理 | 联系设备管理员 |

不要为了跟教程界面完全一致，贸然更改整个系统、磁盘格式或安全配置。先确认自己的版本与目标功能。
