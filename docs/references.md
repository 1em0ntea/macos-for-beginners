# 版本差异与官方参考

[返回目录](../README.md)

## 本教程怎样核对

官方页面核对日期：**2026-10-05**。章节使用独立编写的解释和练习，功能入口与快捷键参照下列 Apple 官方资料。本教程没有在全部版本和全部硬件上逐项实机验证。

Apple 的在线手册有版本选择器。不带版本号的链接可能打开较新的版本，阅读时应切换到自己“关于本机”显示的版本。第三方应用的行为以其当前官方说明为准。

## 最需要留意的差异

| 你看到的现象 | 可能原因 | 如何继续 |
| --- | --- | --- |
| 教程说“系统设置”，电脑上是“系统偏好设置” | macOS Monterey 12 或更早的界面命名 | 用对应版本的官方手册查入口 |
| 找不到与旧教程相同的启动台图标 | 应用浏览入口随版本变化 | 用聚焦，或访达“应用程序”文件夹 |
| 绿色按钮的文字和布局不同 | 系统版本、应用支持情况不同 | 先手动拖移并调整大小 |
| 拖到边缘没有新版平铺提示 | 较早版本、相关开关关闭，或窗口不支持 | Sequoia 15 起的增强功能另行检查；手动并排仍可用 |
| “文本输入”与“文字输入”，“隐私与安全性”与“隐私与安全”不一致 | 不同资料或界面的译名 | 在系统设置中搜索“输入法”或权限名称 |
| 调度中心手势需要三指或四指 | 手势配置与版本不同 | 看“触控板”页面的当前演示 |
| 截图格式或录制窗口选项不同 | 较新系统与硬件加入了额外选项 | 以截图工具栏实际提供的选项为准 |
| 找不到“密码”独立应用 | 系统版本差异 | 在系统设置或 Safari 设置中查看对应入口 |
| 某些设置无法修改 | 权限限制或组织设备管理 | 联系设备管理员 |

不要为了跟教程界面完全一致，贸然更改整个系统、磁盘格式或安全配置。先确认自己的版本与目标功能。

## 维护原则

发现入口变化时，先检查对应版本的官方手册，再更新章节和这里的核对日期。反馈请附 macOS 版本、所在章节和你实际看到的界面文字；不要只说“教程过时了”。

未来若添加截图，需说明拍摄版本、清除个人信息，并保留素材权利说明。
