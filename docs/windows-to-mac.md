# Windows → Mac 对照

[返回目录](../README.md)

你原来会做的事情，在 Mac 上大多也能完成。先找对应入口，再留意行为上的差别。这张表是常见使用习惯的对照，不表示两个系统的功能完全相同。

## 常见任务对应

| 你在 Windows 上熟悉的操作 | Mac 上先找这里 | 要留意的差别 |
| --- | --- | --- |
| 文件资源管理器 | 访达（Finder） | Return 常用于重命名，`⌘ O` 打开选中项目 |
| 任务栏里的应用图标 | 程序坞（Dock） | 图标可以保留为入口，也能表示运行中的应用 |
| 搜索应用和文件 | 聚焦（Spotlight） | `⌘ 空格` 通常可打开 |
| 系统设置 / 控制面板 | 系统设置 | 用内置搜索找功能名 |
| `Ctrl C` / `Ctrl V` | `⌘ C` / `⌘ V` | Mac 的 Control 不是 Command |
| `Alt Tab` | `⌘ Tab` | 主要切换应用，同一应用的多个窗口另行选择 |
| `F2` 重命名 | 访达中按 Return | 文本编辑中的 Return 仍用于换行或确认 |
| 文件剪切后粘贴 | `⌘ C` 后在目标按 `⌥ ⌘ V` | 这是访达文件移动，不是文字剪切 |
| 点关闭按钮退出程序 | 红色关闭按钮与 `⌘ Q` | 关窗口不一定退出应用 |
| `Win L` 锁屏 | `⌃ ⌘ Q` | 也可用 ` → 锁定屏幕` |
| 截图工具 / Print Screen | `⇧ ⌘ 5` | 另有全屏和区域快捷键 |
| 任务管理器里的进程信息 | 活动监视器 | 日常卡住可先用 `⌥ ⌘ Esc` 处理目标应用 |
| `.exe` 安装程序 | Mac 版应用、DMG 或 PKG | Windows 可执行文件不能作为普通 Mac 应用直接安装 |
| C 盘、D 盘 | 访达中的磁盘和位置 | 不必为了沿用盘符习惯先给 Mac 分区 |

参考：[Apple 从 Windows 转用 Mac 说明](https://support.apple.com/zh-cn/guide/mac-help/mchlbc684e49/mac)、[键盘快捷键](https://support.apple.com/zh-cn/102650)。

## Windows 键盘接到 Mac

常见映射是 Windows 标志键对应 Command，Alt 对应 Option。不同键盘、驱动或自定义设置可能不同，连接后先用文本编辑测试拷贝和粘贴。如果需要调整，搜索系统设置里的“修饰键”。不要把键帽上的名称直接等同于系统里的功能。

## 迁移资料的稳妥顺序

1. 先给旧电脑的重要资料保留独立备份。
2. 列出要搬的文稿、照片、书签，以及需要继续使用的软件。
3. 只搬一小批测试资料，到 Mac 上打开确认内容与格式。
4. 需要自动迁移时，在 Mac 上用聚焦打开“迁移助理”，并在 Windows 电脑上按 Apple 官方说明下载与 macOS 版本匹配的 Windows 迁移助理。
5. 资料传输完成后，在 Mac 上打开迁入的文稿、照片和所需账户数据，确认内容和保存位置。
6. 重要数据和工作流程验证通过后，再决定怎样处理旧电脑。

迁移工具主要搬资料和账户内容，不会让 Windows 软件自动变成 Mac 软件。工作所需的专用程序要单独确认 Mac 版本或其他可用方案。迁移助理的具体范围、要求和步骤以 [Apple 官方迁移说明](https://support.apple.com/zh-cn/102565)为准。

用外置磁盘传资料时，先确认 Mac 能读取其格式。需要双方读写时可了解 ExFAT。重新格式化会删除现有内容，不要拿唯一资料所在的磁盘试验。[Apple 外置磁盘说明](https://support.apple.com/zh-cn/101830)

## 三个最容易误判的地方

- 从程序坞移除图标，只是移除入口，软件通常还在。
- “最近使用”是汇总视图，删除里面的文件会影响真实文件。
- iCloud 云盘把变化同步到其他设备，不会自动为你提供整台 Mac 的独立备份。
