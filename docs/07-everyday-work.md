# 07 · 完成一次日常工作

[上一章](06-windows-and-multitasking.md) · [返回目录](../README.md) · [下一章：设置与隐私](08-settings-and-privacy.md)

**本章目标：** 用自带工具查资料、记录与保存，再生成 PDF 和截图，检查结果是否适合分享。

**开始前：** 本章沿用[第四章](04-finder-and-files.md)建立的“Mac 入门练习”文件夹，以及里面的“草稿”和“成品”。还没有这些文件夹时，先完成第四章第 3 节。核心练习只用 Safari、文本编辑和预览，不需要登录 Apple 账户。

## 1. 从浏览器开始

打开 Safari，点地址栏输入网址，按 Return。也可以在地址栏输入关键词进行搜索。

这三个操作很常用：

- `⌘ L`：把输入位置移到地址栏。
- `⌘ T`：打开新的标签页。
- `⌘ F`：在当前网页里查找文字。

下载完成后，可以从 Safari 的下载列表或访达“下载”文件夹找到文件。下载记录里的“移除记录”与删除实际文件是两回事。

## 2. 记笔记与保存文件

本教程用“文本编辑”写简单文稿，并明确保存到本地项目文件夹。这样可以完成整套练习，无需登录 Apple 账户。

应用的保存方式并不都一样。有些应用会自动保存，有些要求先命名或手动存储。第一次使用时做一次验证：存储、关闭、重新打开，检查内容是否还在。

如果之后需要交付给别人，先确认对方需要什么格式。编辑用的文稿和方便阅读的 PDF 可以分别保留。导出或打印成 PDF 后，原来的可编辑文件仍然有价值。

## 3. 生成 PDF，再用预览检查

“预览”（Preview）可以打开很多图片和 PDF。连按文件通常就能用默认应用打开。如果默认不是预览，右键文件，选择“打开方式”，再选择预览。

要把支持打印的文稿变成 PDF：

1. 在对应应用中选择 `文件 → 打印`。
2. 在打印对话框里找到“PDF”菜单。
3. 选择“保存为 PDF”（部分界面称“存储为 PDF”），设置名称和位置。
4. 用预览打开结果，检查页数、文字和版面。

这项操作不需要连接打印机。不同应用的打印界面会略有不同。导出 PDF 以后务必看一眼，别只根据文件名判断成功。[Apple 保存 PDF 说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp1531/mac)

需要打印到纸上或扫描纸质文稿时，再看[配件、打印与扫描](accessories-and-printing.md)，按自己的设备选择步骤。

## 4. 截图与标记

| 需要什么 | 操作 |
| --- | --- |
| 整个屏幕 | `⇧ ⌘ 3` |
| 自己框选的区域 | `⇧ ⌘ 4`，再拖出矩形 |
| 一个窗口 | `⇧ ⌘ 4`，再按空格，点目标窗口 |
| 查看截图和录屏工具 | `⇧ ⌘ 5` |

默认截图会存到桌面。在 `⇧ ⌘ 5 → 选项` 里可以查看或更改保存位置。框选时按 Esc 可取消。[Apple 截图说明](https://support.apple.com/zh-cn/102646)

### 给截图加说明

先在访达选中截图，按 `⌘ D` 在原位置生成副本。给副本起一个能分清的名称，原截图继续保留。[Apple 访达文件快捷键](https://support.apple.com/zh-cn/102650)

用预览打开副本，在它的工具栏查找“标记”工具，可添加箭头、文字或简单图形。完成后存储，关闭再打开，确认说明仍在。[Apple 标记文件说明](https://support.apple.com/zh-cn/guide/mac-help/mchl1fd88863/mac)

## 5. 分享前做一次检查

可以在聊天、邮件或网页的附件入口选择文件，也可以把文件拖进支持上传的区域。等待上传完成，再确认文件名和内容。

多份文件想一起打包时，在访达选中它们，右键选择“压缩”，会生成一个 ZIP 文件。接收方解压后再使用其中的文件。打包后检查内容是否齐全，再决定是否分享。[Apple 压缩说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp2528/mac)

给附近的 iPhone、iPad 或 Mac 传文件，可以尝试隔空投送：在访达选中文件，右键选择共享菜单中的隔空投送，先与接收方核对显示的设备名称，再选择对方的设备。双方需要打开 Wi-Fi 和蓝牙，并检查接收设置。传送完成后确认对方收到。使用同一 Apple 账户的设备可能自动接收。[Apple 隔空投送说明](https://support.apple.com/zh-cn/guide/mac-help/mh35868/mac)

分享截图前，检查地址、账号、通知和其他私人内容。需要去除敏感信息时，可以重新截取只包含必要内容的区域。PDF 上画一个覆盖框不一定真正删除底下的文字，不能把普通标记当成可靠的脱敏工具。

## 小练习：交付一份结果

1. 用 Safari 打开本教程任意一章，挑出三个刚学会的操作。
2. 在文本编辑选择 `文件 → 新建`，写下这三个操作。把文稿命名为“Mac 学习记录”，存到“Mac 入门练习”里的“成品”，保留可编辑的格式。
3. 保持“Mac 学习记录”的文稿窗口在前面，从文本编辑的 `文件 → 打印` 将这份文稿保存为 PDF。名称也用“Mac 学习记录”，保存位置仍选“成品”。生成 PDF 后，第 2 步的可编辑文稿继续保留。
4. 在访达打开“成品”，用预览打开“Mac 学习记录.pdf”，确认三条记录和页数都正确。
5. 按 `⇧ ⌘ 5`，打开“选项”，记下原来的保存选项。本次练习将保存位置选为“桌面”，再按 Esc 退出截图工具栏。
6. 按 `⇧ ⌘ 4`，拖出矩形框选 PDF 中需要的部分，松开鼠标或触控板后完成截图。在访达打开“桌面”，找到刚生成的截图，按空格快速查看，确认截到了所需内容，再按空格关闭快速查看。
7. 在访达选中这张截图，按 `⌘ D` 生成副本。只把副本重命名为“学习截图”，显示后缀时保留原后缀。选中“学习截图”按 `⌘ C`，打开“Mac 入门练习”里的“成品”，按 `⌥ ⌘ V` 将这份副本移动到“成品”。原截图留在桌面。
8. 用预览打开“成品”里的“学习截图”，加一句说明，存储并关闭。
9. 关闭“Mac 学习记录”的文稿和 PDF 窗口，再从“成品”重新打开下表中的三个结果并检查。若第 5 步更改了截图保存选项，检查后按 `⇧ ⌘ 5 → 选项` 改回原选项，再按 Esc 退出。实际发送不是练习的必要步骤。

| 留在“成品”的结果 | 检查什么 |
| --- | --- |
| “Mac 学习记录”的可编辑文稿，通常是 `.rtf` 或 `.txt` | 能用文本编辑打开并继续修改 |
| “Mac 学习记录.pdf” | 能打开，文字、页数和版面正确 |
| “学习截图”的图片文件 | 说明已保存，没有多余的私人内容 |

**完成标准：** 你能直接在“成品”中找到并打开这三个结果，也知道编辑原稿、PDF 和截图各自用来做什么。

## 6. 按需：更改默认应用

默认应用决定点开链接或文件时通常使用哪个应用。先完成上面的练习，确实想换应用时再做下面的设置。

### 换成自己喜欢的默认浏览器

“默认浏览器”决定点开网页链接时通常使用哪个应用。如果已经安装了其他浏览器，在 macOS Ventura 13 及之后可以打开 `系统设置 → 桌面与程序坞`，找到“默认网页浏览器”，选择它。以后点一个网页链接，检查是否用所选浏览器打开。

修改默认浏览器不会自动搬走 Safari 里的书签和其他资料，数据导入要按目标浏览器的说明另做。也不需要为了更改默认浏览器登录 Apple 账户。[Apple 默认浏览器说明](https://support.apple.com/zh-cn/102362)

### 让一类文件默认用指定应用打开

临时的“打开方式”只决定这一次使用什么应用。想让 PDF 等一类文件通常用指定应用打开，可以这样做：

1. 在访达选中一份对应类型的测试文件，选择 `文件 → 显示简介`，或按 `⌘ I`。
2. 展开“打开方式”，记下原来的应用，再选择已安装且能打开这种格式的应用。
3. 点“全部更改”，按提示确认。这会改变同类文件的默认打开方式，不只影响这一份文件。
4. 关闭简介窗口，连按另一份同类型文件，检查打开它的应用。想改回时，重复上述步骤并选回原来的应用。

只想更改所选文件的默认应用时，完成第 1、2 步后直接关闭“显示简介”窗口，不点“全部更改”。以后连按这一份文件会使用所选应用，其他同类文件不受这次设置影响。只想临时打开一次，则使用右键菜单中的“打开方式”。更改打开应用不会转换文件格式，不能让不支持 PDF 的软件突然读懂 PDF。[Apple 默认打开应用说明](https://support.apple.com/zh-cn/guide/mac-help/mh35597/mac)

## 7. 按需：用备忘录记本地笔记

想用“备忘录”随手记内容时，可以使用本地的“我的 Mac”账户。若没有这个位置，在 `备忘录 → 设置` 中启用“我的 Mac”账户，再在该位置新建笔记。这些笔记保存在这台电脑，不需要启用 iCloud 备忘录同步。[Apple 备忘录账户说明](https://support.apple.com/zh-cn/guide/notes/not85d6f7b58/mac)

## 8. 按需：录制操作

需要录制操作时，打开 `⇧ ⌘ 5` 的工具栏，选录制范围和选项，再开始录制，用菜单栏停止按钮结束。先录一小段，确认画面、声音和保存位置。声音能录到什么取决于版本与所选选项。[Apple 录屏说明](https://support.apple.com/zh-cn/102618)
