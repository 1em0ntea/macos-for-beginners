# 07 · 完成一次日常工作

[上一章](06-windows-and-multitasking.md) · [返回目录](../README.md) · [下一章：设置与隐私](08-settings-and-privacy.md)

**本章目标：** 用自带工具完成“查资料 → 记录 → 保存 → 截图或 PDF → 分享”这一轮工作。

## 1. 从浏览器开始

打开 Safari，点地址栏输入网址，按 Return。也可以在地址栏输入关键词进行搜索。

这三个操作很常用：

- `⌘ L`：把输入位置移到地址栏。
- `⌘ T`：打开新的标签页。
- `⌘ F`：在当前网页里查找文字。

下载完成后，可以从 Safari 的下载列表或访达“下载”文件夹找到文件。下载记录里的“移除记录”与删除实际文件是两回事。

## 2. 记笔记与保存文件

随手记内容可以用“备忘录”；需要明确保存成文件、放进项目文件夹的简单文稿，可以用“文本编辑”。

应用的保存方式并不都一样。有些应用会自动保存，有些要求先命名或手动存储。第一次使用时做一次验证：存储、关闭、重新打开，检查内容是否还在。

如果之后需要交付给别人，先确认对方需要什么格式。编辑用的文稿和方便阅读的 PDF 可以分别保留。导出或打印成 PDF 后，原来的可编辑文件仍然有价值。

## 3. 截一张有用的图

| 需要什么 | 操作 |
| --- | --- |
| 整个屏幕 | `⇧ ⌘ 3` |
| 自己框选的区域 | `⇧ ⌘ 4`，再拖出矩形 |
| 一个窗口 | `⇧ ⌘ 4`，再按空格，点目标窗口 |
| 查看截图和录屏工具 | `⇧ ⌘ 5` |

默认截图会存到桌面；在 `⇧ ⌘ 5 → 选项` 里可以查看或更改保存位置。框选时按 Esc 可取消。支持 HDR 截图的较新系统可选择捕捉格式，想方便传给别人时优先检查兼容性选项。[Apple 截图说明](https://support.apple.com/zh-cn/102646)

需要录制操作时，打开 `⇧ ⌘ 5` 的工具栏，选录制范围和选项，再开始录制，用菜单栏停止按钮结束。先录一小段，确认画面、声音和保存位置；声音能录到什么取决于版本与所选选项。[Apple 录屏说明](https://support.apple.com/zh-cn/102618)

## 4. 用预览看图片和 PDF

“预览”（Preview）可以打开很多图片和 PDF。连按文件通常就能用默认应用打开；如果默认不是预览，右键文件，选择“打开方式”，再选择预览。

在工具栏查找“标记”工具，可给练习截图添加箭头、文字或简单图形。练习前先复制一份文件，避免改动原件。[Apple 标记文件说明](https://support.apple.com/zh-cn/guide/mac-help/mchl1fd88863/mac)

要把支持打印的文稿变成 PDF：

1. 在对应应用中选择 `文件 → 打印`。
2. 在打印对话框里找到“PDF”菜单。
3. 选择“保存为 PDF”（部分界面称“存储为 PDF”），设置名称和位置。
4. 用预览打开结果，检查页数、文字和版面。

这项操作不需要连接打印机。不同应用的打印界面会略有不同。导出 PDF 以后务必看一眼，别只根据文件名判断成功。[Apple 保存 PDF 说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp1531/mac)

## 5. 分享前做一次检查

可以在聊天、邮件或网页的附件入口选择文件，也可以把文件拖进支持上传的区域。等待上传完成，再确认文件名和内容。

给附近的 iPhone、iPad 或 Mac 传文件，可以尝试隔空投送：在访达选中文件，右键选择共享菜单中的隔空投送，选择正确接收设备。双方需要打开 Wi-Fi 和蓝牙，并检查接收设置；传送完成后确认对方收到。使用同一 Apple 账户的设备可能自动接收。[Apple 隔空投送说明](https://support.apple.com/zh-cn/guide/mac-help/mh35868/mac)

分享截图前，检查地址、账号、通知和其他私人内容。需要去除敏感信息时，可以重新截取只包含必要内容的区域。PDF 上画一个覆盖框不一定真正删除底下的文字，不能把普通标记当成可靠的脱敏工具。

## 小练习：交付一份结果

1. 在文本编辑写一份“Mac 学习记录”，存到“Mac 入门练习/成品”。
2. 把它通过打印对话框存成 PDF。
3. 用预览打开 PDF，确认文字正确。
4. 截取 PDF 的一部分，在截图副本上加一句说明。
5. 找到这两个文件，确认它们的保存位置。实际发送不是练习的必要步骤。

**完成标准：** 你有一份能继续编辑的文稿、一份能打开的 PDF，以及一张只包含必要内容的截图。
