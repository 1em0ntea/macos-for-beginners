# 06 · 窗口与多任务

[上一章](05-install-and-remove-apps.md) · [返回目录](../README.md) · [下一章：日常工作](07-everyday-work.md)

**本章目标：** 同时用两个应用工作，并找回被遮住、最小化或放在其他空间的窗口。

## 1. 应用、窗口和标签页

用 Safari 举例：Safari 是一个应用；它可以打开多个窗口；每个窗口里又可以有多个网页标签页。

因此，切换应用、切换窗口和切换标签页是三件不同的事。刚开始只需记住：

| 想做什么 | 先用哪种方法 |
| --- | --- |
| 从 Safari 切到文本编辑 | `⌘ Tab`，或点程序坞图标 |
| 找 Safari 的另一个窗口 | Safari 的“窗口”菜单，或调度中心 |
| 切到另一个网页 | 点对应的标签页 |

`⌘ Tab` 的用法是按住 Command，反复按 Tab 选到目标应用，再松开 Command。它不保证替你恢复每个最小化窗口。[Apple 窗口操作说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp2469/mac)

## 2. 窗口不见了，先按顺序找

1. 看程序坞：点目标应用的图标，检查是否能回到它。
2. 看该应用的“窗口”菜单：选择需要的窗口名称。
3. 看是否最小化：点程序坞中的窗口缩略图；如果窗口最小化到应用图标，可右键点按图标选择窗口。
4. 打开调度中心：默认可按 `⌃ ↑`，查看当前桌面的窗口和顶部的其他空间。

调度中心（Mission Control）把窗口和桌面空间集中展示。全屏应用可能在单独的空间里，所以“当前桌面看不到”不等于“应用退出了”。

## 3. 先学手动并排

这是不依赖较新平铺功能的通用练习：

1. 打开 Safari 和文本编辑。
2. 拖移 Safari 窗口的标题区域到屏幕左侧。
3. 拖移窗口边缘调整大小，留出右半屏。
4. 把文本编辑放到右侧，同样调整大小。

应用若规定了最小窗口宽度，不必硬挤成精确的一半。让两个窗口都能看清就可以。

## 4. 全屏与填满桌面

绿色按钮通常可以进入全屏，也可能在悬停时显示更多布局选项。全屏会让应用在专门的空间里工作，菜单栏和程序坞可能暂时隐藏。把指针移到屏幕顶部，可重新找到按钮并退出全屏。

想让窗口变大又保留普通桌面，可以手动拖大窗口；较新系统也可能在绿色按钮菜单中提供“填充”等选项。不要把“全屏”和“占满可用桌面”混成同一个状态。

## 5. 系统平铺与分屏浏览

macOS Sequoia 15 及之后提供更方便的窗口平铺：可将窗口拖到屏幕边缘，等布局提示出现后松开，也可把指针放到绿色按钮上选择布局。开关与行为在“桌面与程序坞”相关设置里调整。[Apple 平铺说明](https://support.apple.com/zh-cn/guide/mac-help/mchlef287e5d/mac)、[Sequoia 功能说明](https://support.apple.com/zh-cn/120283)

较早系统和不同应用的绿色按钮菜单可能显示不同文字，有些提供“分屏浏览”，会把两个窗口放进全屏空间。找不到新版布局时，先采用手动并排；这是本章练习的基础方式。

“台前调度”是另一种组织窗口的方式，可以以后再尝试。如果你的窗口总被自动分组或放到一边，查看控制中心或系统设置中的台前调度开关，先弄清当前状态。

## 小练习：边看边写

打开本教程任意一章，让 Safari 在左侧、文本编辑在右侧，写下三个刚学会的操作。存储文稿，然后把一个窗口最小化，再把它找回来。

**完成标准：** 你能切换两个应用，知道最小化窗口与全屏空间该到哪里找。
