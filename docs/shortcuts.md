# 快捷键速查

[返回目录](../README.md) · [按键与输入法教程](03-keyboard-and-trackpad.md)

符号：`⌘` Command · `⌥` Option · `⌃` Control · `⇧` Shift。按住组合中的修饰键，再按最后一个键。

快捷键可能被应用、自定义设置或输入法改动。拿不准时看当前应用的菜单，菜单项右侧显示的组合最直接。

## 先记住这一组

| 目标 | 快捷键 | 使用范围 |
| --- | --- | --- |
| 拷贝 / 粘贴 | `⌘ C` / `⌘ V` | 常见编辑操作，也可用于访达文件 |
| 撤销 | `⌘ Z` | 应用支持时可用 |
| 全选 | `⌘ A` | 当前编辑区域或文件列表 |
| 存储 | `⌘ S` | 支持存储文稿的应用 |
| 查找 | `⌘ F` | 文稿、网页或访达，各自含义略有不同 |
| 打开聚焦 | `⌘ 空格` | 系统搜索 |
| 切换应用 | `⌘ Tab` | 按住 Command，再按 Tab 选择 |
| 关闭窗口或标签页 | `⌘ W` | 不一定退出应用 |
| 退出应用 | `⌘ Q` | 当前应用 |

常用组参考：[Apple 基础快捷键说明](https://support.apple.com/zh-cn/guide/mac-help/mchlgtd_kbd01/mac)。

## 访达中的文件

| 目标 | 快捷键 | 提醒 |
| --- | --- | --- |
| 新建文件夹 | `⇧ ⌘ N` | 先进入目标位置 |
| 打开自己的用户文件夹 | `⇧ ⌘ H` | 也可选“前往 → 个人” |
| 打开上层文件夹 | `⌘ ↑` | 回到当前文件夹的外面一层 |
| 查找文件 | `⌘ F` | 确认当前文件夹或“这台 Mac”的搜索范围 |
| 打开选中项目 | `⌘ O` | 也可以连按两下 |
| 重命名选中项目 | `Return` | 再按 Return 确认 |
| 快速查看 | `空格` | 支持预览的文件 |
| 显示简介 | `⌘ I` | 查看类型、大小、位置等 |
| 复制文件到目标位置 | `⌘ C`，到目标后 `⌘ V` | 保留原件 |
| 移动文件到目标位置 | `⌘ C`，到目标后 `⌥ ⌘ V` | 文件离开原位置 |
| 移到废纸篓 | `⌘ Delete` | 删除前认清文件与同步位置 |
| 推出选中磁盘 | `⌘ E` | 等推出成功再拔掉 |

文本剪切 `⌘ X` 与访达中的文件移动不要混用。文件相关组合参考：[Apple 完整快捷键列表](https://support.apple.com/zh-cn/102650)。

多选时，`Command + 点按` 选择不相邻项目，`Shift + 点按` 选择列表中连续的一段。批量操作前检查选中了什么。[Apple 选择项目说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp1378/mac)

列表整理可以先记 `⌘ 2`：在访达切到列表视图，再点列标题排序。详细步骤见[第四章](04-finder-and-files.md)。

## 编辑文字时按需查

先点文稿的编辑区域。这些组合通常用于文字编辑，不能直接套到访达的文件列表。

| 目标 | 快捷键 | 提醒 |
| --- | --- | --- |
| 移到当前行开头 / 末尾 | `⌘ ←` / `⌘ →` | 应用支持时可用 |
| 逐字扩展选择范围 | `⇧ ←` / `⇧ →` | 从当前插入点开始 |
| 删除光标前的字符 | `Delete` | 有选中文字时删除选中内容 |
| 删除光标后的字符 | `Fn Delete` | 常用于没有独立向前删除键的键盘 |
| 粘贴并匹配目标样式 | 常见为 `⌥ ⇧ ⌘ V` | 先查看“编辑”菜单，不等于清除所有格式 |

参考：[Apple 文本编辑快捷键](https://support.apple.com/zh-cn/102650)、[粘贴与匹配样式](https://support.apple.com/zh-cn/102553)。先会用鼠标拖选，再逐渐记需要的组合。

## 截图、输入与应急

| 目标 | 快捷键 | 提醒 |
| --- | --- | --- |
| 全屏截图 | `⇧ ⌘ 3` | 默认存到桌面，位置可更改 |
| 区域截图 | `⇧ ⌘ 4` | 拖移框选，Esc 取消 |
| 窗口截图 | `⇧ ⌘ 4`，再按 `空格` | 然后点窗口 |
| 截图与录屏工具 | `⇧ ⌘ 5` | 在“选项”中看保存位置 |
| 切换输入法 | 常见为 `⌃ 空格` | 按实际输入法快捷键设置确认 |
| 调度中心 | 默认 `⌃ ↑` | 快捷键可更改 |
| 锁定屏幕 | `⌃ ⌘ Q` | 也可用苹果菜单 |
| 强制退出窗口 | `⌥ ⌘ Esc` | 可能丢失未保存内容 |

参考：[截图说明](https://support.apple.com/zh-cn/102646)、[输入法切换](https://support.apple.com/zh-cn/guide/mac-help/mchlp1406/mac)、[强制退出说明](https://support.apple.com/zh-cn/102586)。
