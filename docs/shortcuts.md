# 快捷键速查

[返回目录](../README.md) · [按键与输入法教程](03-keyboard-and-trackpad.md)

符号：`⌘` Command · `⌥` Option · `⌃` Control · `⇧` Shift。按住组合中的修饰键，再按最后一个键。

快捷键可能被应用、自定义设置或输入法改动。拿不准时看当前应用的菜单，菜单项右侧显示的组合最直接。

## 先记住这一组

| 目标 | 快捷键 | 使用范围 |
| --- | --- | --- |
| 拷贝 / 粘贴 | `⌘ C` / `⌘ V` | 常见编辑操作，也可用于访达文件 |
| 撤销 | `⌘ Z` | 应用支持时可用 |
| 全选 | `⌘ A` | 当前编辑区域或文件列表 |
| 存储 | `⌘ S` | 支持存储文稿的应用 |
| 查找 | `⌘ F` | 文稿、网页或访达，各自含义略有不同 |
| 打开聚焦 | `⌘ 空格` | 系统搜索 |
| 切换应用 | `⌘ Tab` | 按住 Command，再按 Tab 选择 |
| 关闭窗口或标签页 | `⌘ W` | 不一定退出应用 |
| 退出应用 | `⌘ Q` | 当前应用 |

常用组参考：[Apple 基础快捷键说明](https://support.apple.com/zh-cn/guide/mac-help/mchlgtd_kbd01/mac)。

## 访达中的文件

| 目标 | 快捷键 | 提醒 |
| --- | --- | --- |
| 新建文件夹 | `⇧ ⌘ N` | 先进入目标位置 |
| 打开选中项目 | `⌘ O` | 也可以连按两下 |
| 重命名选中项目 | `Return` | 再按 Return 确认 |
| 快速查看 | `空格` | 支持预览的文件 |
| 显示简介 | `⌘ I` | 查看类型、大小、位置等 |
| 复制文件到目标位置 | `⌘ C`，到目标后 `⌘ V` | 保留原件 |
| 移动文件到目标位置 | `⌘ C`，到目标后 `⌥ ⌘ V` | 文件离开原位置 |
| 移到废纸篓 | `⌘ Delete` | 删除前认清文件与同步位置 |
| 推出选中磁盘 | `⌘ E` | 等推出成功再拔掉 |

文本剪切 `⌘ X` 与访达中的文件移动不要混用。文件相关组合参考：[Apple 完整快捷键列表](https://support.apple.com/zh-cn/102650)。

## 截图、输入与应急

| 目标 | 快捷键 | 提醒 |
| --- | --- | --- |
| 全屏截图 | `⇧ ⌘ 3` | 默认存到桌面，位置可更改 |
| 区域截图 | `⇧ ⌘ 4` | 拖移框选，Esc 取消 |
| 窗口截图 | `⇧ ⌘ 4`，再按 `空格` | 然后点窗口 |
| 截图与录屏工具 | `⇧ ⌘ 5` | 在“选项”中看保存位置 |
| 切换输入法 | 常见为 `⌃ 空格` | 按实际输入法快捷键设置确认 |
| 调度中心 | 默认 `⌃ ↑` | 快捷键可更改 |
| 锁定屏幕 | `⌃ ⌘ Q` | 也可用苹果菜单 |
| 强制退出窗口 | `⌥ ⌘ Esc` | 可能丢失未保存内容 |

参考：[截图说明](https://support.apple.com/zh-cn/102646)、[输入法切换](https://support.apple.com/zh-cn/guide/mac-help/mchlp1406/mac)、[强制退出说明](https://support.apple.com/zh-cn/102586)。
