# 10 · 常见问题与排查

[上一章](09-backup-and-icloud.md) · [返回目录](../README.md) · [快捷键速查](shortcuts.md)

**本章目标：** 从影响最小的检查开始，能解决常见问题，也能把问题描述清楚。

## 1. 应用卡住或一直显示彩色转圈

1. 稍等片刻，尤其是正在导出、安装或处理大文件时。
2. 试着切到别的应用。若只有一个应用卡住，先处理它。
3. 尝试 `⌘ Q` 正常退出。
4. 无响应时按 `⌥ ⌘ Esc`，选那个应用并“强制退出”。未保存工作可能丢失。
5. 重新打开应用。如果问题反复发生，查看应用更新，保存工作后重新启动 Mac。

如果访达卡住，可在强制退出窗口选择访达并“重新开启”。整台电脑完全无响应、菜单也无法重启时，才长按电源按钮约 10 秒关机，再开机。不要在系统更新过程中把这种方式当成常规操作。[Apple 强制退出说明](https://support.apple.com/zh-cn/102586)

## 2. 文件找不到

1. 打开访达“下载”“文稿”或你刚才选择的保存位置。
2. 在访达按 `⌘ F` 搜索文件名，注意搜索范围是当前文件夹还是“这台 Mac”，可按[文件查找步骤](04-finder-and-files.md)检查。
3. 检查“最近使用”、iCloud 云盘和废纸篓。
4. 若文件仍在应用中打开，查看标题或存储信息，确认路径。
5. 误删且不在废纸篓时，查找独立备份或对应服务的恢复功能。

“最近使用”中的项目不是多出来的一份文件，不要试图通过删除这里的项目来“清掉记录”。

## 3. 点击程序坞后看不到窗口

应用可能没有打开窗口、窗口被最小化，或在另一个全屏空间里。先查“窗口”菜单和调度中心，再决定是否新建窗口。[窗口查找步骤](06-windows-and-multitasking.md)

## 4. 快捷键不起作用，或输入不了中文

先点按需要输入的区域，检查菜单栏的当前应用和输入法。把 `⌘` 与 `⌃` 分清楚。快捷键也可能被其他工具占用。

在 `系统设置 → 键盘 → 键盘快捷键` 查看实际绑定。中文输入法缺失时按[第三章](03-keyboard-and-trackpad.md)添加。如果某应用禁用一个输入法，换到文本编辑测试，判断是不是应用限制。

## 5. Wi-Fi 连上了但网页打不开

1. 换一个网页，判断是某个网站还是所有网站的问题。
2. 检查是否需要公共网络登录，以及其他设备能否上网。
3. 检查 Wi-Fi 是否连接到正确网络。
4. 查看正在使用的 VPN 或代理是否有故障。受公司管理时按管理员要求处理。
5. 保存工作后尝试重新连接网络或重新启动 Mac。

自己家里的路由器可以按其说明检查，别随意重启公共或办公网络设备。

## 6. 没有声音，或会议听不到麦克风

在 `系统设置 → 声音` 检查输出设备和音量，确认没有把声音送到未使用的蓝牙耳机或显示器。

麦克风问题同时检查三处：系统声音输入、会议应用自己的设备选择，以及隐私设置中的麦克风权限。屏幕分享没有画面，则查看对应的屏幕录制权限。改变权限后可能要重启应用。

第一次连接蓝牙耳机时，先按[配件章节](accessories-and-printing.md)完成配对，再检查输入和输出设备。

## 7. U 盘能读，不能保存进去

先查看剩余空间，再在访达选中磁盘，按 `⌘ I` 看“格式”和权限。NTFS 是常见原因：Mac 原生通常能读取，但不能直接写入。也可能是权限或磁盘本身的问题。[Apple 外置驱动器排查说明](https://support.apple.com/zh-cn/101830)

不要直接点“抹掉”来试验。需要 Mac 和 Windows 共用磁盘时可了解 ExFAT，但更改格式会清除现有内容，必须先备份。已经存着唯一资料的磁盘，先解决资料副本问题。

## 8. 软件打不开，提示开发者或兼容性问题

核对下载来源、Mac 版本和芯片要求，优先从开发者官网获取兼容版本。安全提示要看完整文字，不同提示代表不同情况。先看[安装章节的提示对照](05-install-and-remove-apps.md)，再按 [Apple 安全说明](https://support.apple.com/zh-cn/102445)和开发者支持文档排查。

不要为了打开一个来源不明的文件关闭全部系统保护。

## 9. 磁盘空间快满了

先到系统设置搜索“储存空间”，看占用情况。检查自己认识的大下载文件、已不需要的安装文件和应用。删除前确认是否有重要内容或云端同步影响，再处理废纸篓。

不认识的系统项目先保留。“系统数据”这一类别不是一个可以整块安全删除的文件夹。

## 10. 忘记 Mac 登录密码

先认清当前画面。如果是 Mac 本地用户的登录窗口，输入的是 **Mac 登录密码**，不是 Apple 账户密码。

1. 检查大写锁定状态和登录窗口的输入法，尤其是密码中含字母或符号时。
2. 查看密码提示和界面提供的重设选项。最多输入三次密码后可能出现相关选项，如果提示账户已锁定，等到界面显示的时间结束，不要继续反复尝试。
3. 按当前 Mac 提供的恢复方式操作。已有文件保险箱恢复密钥时，保留好它并在界面要求时使用。若要求 Apple 账户，核对是否是此前用于这台 Mac 的账户，不要为了试错另建一个账户。
4. 登录窗口没有可用的重设选项时，参照 [Apple 密码恢复说明](https://support.apple.com/zh-cn/102633)继续。需要进入 macOS 恢复时，按[对应机型的进入说明](https://support.apple.com/zh-cn/102518)操作，Apple 芯片与 Intel Mac 的方法不同。

恢复选项取决于这台 Mac 的既有设置。**不登录 Apple 账户的使用方式，应提前保存好 Mac 登录密码，并在启用文件保险箱时把恢复密钥留在电脑之外。** 文件保险箱恢复密钥与 Apple 账户恢复密钥不能互相替代。[文件保险箱说明](https://support.apple.com/zh-cn/guide/mac-help/mh11785/mac)

如果恢复过程提示创建新钥匙串，这不代表旧钥匙串里的网站密码也已经找回。公司或学校管理的 Mac 先联系管理员。涉及唯一资料、密码和恢复凭据都不可用时，先向支持人员说明数据状况，避免在没弄清影响前选择“抹掉 Mac”，它会删除本机数据。

如果画面明确显示“激活锁”并要求原所有者的 Apple 账户，这是另一种问题。二手设备应联系原所有者或卖家处理，不能把本教程的“稍后登录”当作跳过激活锁的方法。[Apple Mac 激活锁说明](https://support.apple.com/zh-cn/102541)

## 11. 配件或打印机无法使用

按[配件章节](accessories-and-printing.md)核对线缆、配对、允许连接提示和设备选择。打印失败时，先检查正确的打印机与打印队列，再考虑重新添加设备，不要反复提交相同打印任务。

## 12. 什么情况下找人帮助

无法开机、反复重启、磁盘异常或重要数据无法访问时，可以联系 Apple 支持或设备管理员。进一步操作前先说明备份情况。不要把抹盘、重装或随机删除系统文件当成第一步。

描述问题时，照下面填写：

| 信息 | 示例 |
| --- | --- |
| macOS 版本 | 从“关于本机”抄下版本，不附完整序列号 |
| 应用与版本 | 应用名称，以及其“关于”页面显示的版本 |
| 想完成什么 | 把一份 PDF 保存到 U 盘 |
| 实际发生什么 | 可以打开磁盘，但保存时报某条错误 |
| 触发步骤 | 打开文件 → 选择存储 → 选择磁盘 |
| 已尝试的方法 | 检查空间、换一个测试文件 |
| 数据状况 | 是否有备份，问题是否涉及唯一原件 |

截图保留错误提示即可，遮去账号、私人路径和其他不必要的信息。

## 小练习：写一次清楚的反馈

选一个你之前遇到过的问题，按上表写出描述。如果没有真实问题，就以“找不到刚才下载的文件”为假设练习，不必主动制造故障。

**完成标准：** 别人读完你的描述，知道你想做什么、实际发生什么，以及你已经尝试了什么。
