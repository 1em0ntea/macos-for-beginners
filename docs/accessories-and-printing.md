# 按需阅读：配件、充电、打印与扫描

[返回目录](../README.md) · [设置与隐私](08-settings-and-privacy.md) · [常见问题](10-troubleshooting.md)

**本页目标：** 用手头已有的设备完成连接，检查声音或画面，按需打印和扫描。

这一页不属于基础练习的必做部分。找到与你的设备有关的小节即可，MacBook 的充电内容可以由台式 Mac 读者跳过。以下 Mac 自带设置与本地操作不要求登录 Apple 账户。厂商软件或单位打印系统可能有自己的要求，按实际用途另看说明。

## 1. 先看端口、线缆与允许连接提示

“能插进去”只是第一步，端口、线缆和转换器还需要支持你要用的数据传输或视频输出功能。USB-C 是接头的外形，相同外形的端口和线缆也可能有不同能力。用 ` → 关于本机` 确认机型，再查对应技术规格和配件说明。[Apple 端口识别说明](https://support.apple.com/zh-cn/109523)

| 想连接什么 | 先确认什么 |
| --- | --- |
| U 盘、移动硬盘 | 接头匹配，线缆支持数据传输，需要供电的设备已接电源 |
| 显示器 | Mac 和显示器的端口、线缆及转换器支持所需视频输出 |
| USB 打印机或扫描仪 | 线缆支持数据传输，设备已开机，系统或厂商支持当前 macOS |

在搭载 Apple 芯片的 Mac 笔记本电脑上，新接入的 USB、雷雳配件或 SD 卡可能触发“允许配件连接”的提醒。先解锁 Mac，确认是自己刚接入的设备，再决定允许。拒绝连接后，配件可能仍能充电，却不能传输数据，不能只看充电状态判断连接成功。[Apple 配件允许提示说明](https://support.apple.com/zh-cn/102282)

磁盘成功连接后应出现在访达里，复制结束并检查副本，再按[第四章](04-finder-and-files.md)推出。没有出现时，先检查连接线、供电和允许提示，再按设备说明排查。

## 2. 连接蓝牙鼠标、键盘或耳机

“配对”是让 Mac 与设备建立连接关系。第一次使用时按下面的顺序做：

1. 给配件充好电并开机，按它的说明进入配对或可被发现状态。仅开机不一定已经能被发现。
2. 打开 `系统设置 → 蓝牙`，确认蓝牙已开启。
3. 在附近设备列表中核对设备名称，点“连接”。若提示配对码，按设备说明核对或输入。
4. 等状态显示已连接。鼠标试着移动指针，键盘在文本编辑中输入几个字。
5. 耳机还要打开 `系统设置 → 声音 → 输出`，选择它并播放一小段声音。通话时再检查“输入”，确认麦克风选的是你想使用的设备。

会议应用可能另有输入和输出选择，按[第十章](10-troubleshooting.md)同时检查应用设置和权限。普通蓝牙配对不需要登录 Apple 账户。[Apple 蓝牙连接说明](https://support.apple.com/zh-cn/guide/mac-help/blth1004/mac)

暂时不用时选“断开连接”。若不想继续保留这个配对，使用设备菜单中的“忽略”，以后需要重新配对。找不到设备时，先确认配对状态、电量，以及它是否已经连接到了另一台电脑或手机。

## 3. 连接外接显示器

1. 打开显示器电源，用支持视频输出的线缆连接 Mac 和显示器。
2. 如果显示器有多个输入接口，在它自己的菜单里选择实际接线的输入来源，例如 HDMI。
3. 打开 `系统设置 → 显示器`，确认外接屏幕已被识别。能支持多少台外接屏幕取决于具体 Mac 机型，连接前查看“显示器支持 / 视频支持”的技术规格。[Apple 外接显示器说明](https://support.apple.com/zh-cn/guide/mac-help/mchl7c7ebe08/mac)
4. 有两块或更多屏幕时，点选要调整的显示器，在“用作 / 用途”等菜单中选择需要的模式。

| 模式 | 画面会怎样 | 常见用途 |
| --- | --- | --- |
| 镜像显示 | 两块屏幕显示同一份桌面内容 | 向别人演示 |
| 扩展显示 | 桌面空间延伸到另一块屏幕 | 一边查资料，一边写文稿 |

扩展显示时，用显示器设置中的“排列”把屏幕位置调整得与桌面上的实际摆放接近，再试着把一个测试窗口拖到另一块屏幕。想让某块屏幕成为主要工作位置，可在它的“用作”选项中查看主显示器设置。[Apple 扩展与镜像说明](https://support.apple.com/zh-cn/guide/mac-help/mchlb5f905a1/mac)

文字太小时，先查看所选屏幕的缩放或文字大小选项，一次调一项。如果屏幕没有画面，先检查显示器输入来源、线缆的视频能力和机型支持情况。外接显示器自带扬声器时，声音去向也可能需要在“声音 → 输出”中选择。

## 4. MacBook 的电池与充电

在菜单栏电池菜单或 `系统设置 → 电池` 查看电量和充电状态，页面中的健康信息、优化充电及其他选项会因机型与版本不同而变化。先保留系统的充电管理设置，根据实际使用需要调整。

**插着电源却没有充到 100%，不一定表示故障。** 开启“优化电池充电”时，Mac 可能在电量超过 80% 后延迟继续充电。先看电池菜单的状态，如果需要出门前充满，且菜单提供“立即充满电”，可使用这个选项。[Apple 未充满电说明](https://support.apple.com/zh-cn/guide/mac-help/mchlbfb7e12a/mac)

部分较新系统还提供充电上限，是否可用以当前设备为准。如果 Mac 完全无法充电，或电池状态提示需要维修，按对应提示和 Apple 支持说明检查，不要把所有充电问题都归因于优化功能。

充电和电池管理不需要为了设置而登录 Apple 账户。

## 5. 打印到纸上

打印成 PDF 已在[第七章](07-everyday-work.md)讲过。打印到纸上需要实际打印机，先确认设备已开机、有纸且没有错误提示。

打印机支持“隔空打印”（AirPrint）时，可让它与 Mac 接入同一个 Wi-Fi 网络，通常无需额外安装驱动。使用 USB 打印机时，按设备说明接入线缆。[Apple 添加打印机说明](https://support.apple.com/zh-cn/guide/mac-help/mh14004/mac)

1. 打开 `系统设置 → 打印机与扫描仪`，检查是否已有正确的打印机。
2. 没有时，点“添加打印机、扫描仪或传真机”，核对列表中的型号和设备，再添加。找不到单位网络打印机时，向管理员询问连接方式。
3. 打开一份测试文稿，选择 `文件 → 打印`，或按 `⌘ P`。
4. 确认选中的打印机，检查纸张大小、方向、页码范围、份数和预览。双面、彩色等选项取决于打印机和应用。
5. 如果需要试印，先印一页并检查结果，再提交剩余页面。[Apple 打印说明](https://support.apple.com/zh-cn/guide/mac-help/mh35838/mac)

打印错文件或一直没有出纸时，在“打印机与扫描仪”中选择设备并打开打印队列，检查待处理任务，可以暂停或取消自己的任务。先解决纸张、设备或队列问题，再重新提交，避免同一份文稿重复打印。[Apple 打印问题排查](https://support.apple.com/zh-cn/guide/mac-help/mh14002/mac)

不支持系统自带连接方式的设备，按厂商当前说明获取兼容驱动或软件。下载时核对型号和来源，普通本地打印不需要额外在系统设置登录 Apple 账户。

## 6. 将纸质文稿扫描成文件

这一步适用于扫描仪或带扫描功能的打印机。打印功能已经可用，不代表扫描功能也一定已经配置好。

1. 按设备说明接好扫描仪，把一页测试纸放到扫描玻璃或送纸器上。
2. 打开 `系统设置 → 打印机与扫描仪`，选择设备，再点“打开扫描仪”。没有这个按钮时，先查看[扫描仪设置说明](https://support.apple.com/zh-cn/guide/mac-help/mh28039/mac)和厂商支持情况。
3. 在“扫描至”选择本地保存文件夹，例如[第四章](04-finder-and-files.md)建立的“Mac 入门练习”里的“成品”。尚未建立练习文件夹时，也可以选一个自己能找到的本地文件夹。需要更多选项时，点“显示详细信息”。
4. 为结果命名，按用途选择颜色、扫描范围和文件格式。需要 PDF 时选择界面提供的 PDF 选项，多页合并选项依设备和软件而定。
5. 点“扫描”，完成后去目标文件夹打开结果，检查方向、清晰度、页数和是否缺边。[Apple 扫描说明](https://support.apple.com/zh-cn/guide/mac-help/mh28032/mac)

扫描得到的 PDF 可能主要由图片组成，文字是否可搜索或复制取决于是否启用、支持文字识别。需要编辑文字时，再核对软件提供的识别选项和实际结果。本地扫描可以按上述方式完成，无需为它开启 iCloud。

## 小练习：使用手头已有的设备

选一项与你的设备相符的练习即可：

- 蓝牙设备：连接一次，确认输入或声音输出，再断开连接。
- 外接屏幕：确认画面，已有多块屏幕时比较镜像与扩展，并将布局改回习惯的位置。
- MacBook：找到电池状态，分清电量百分比与当前是否正在充电。
- 打印机：打开测试文稿的打印预览，确认设备、纸张和页数。实际打印按需进行。
- 扫描仪：扫描一页测试纸，存到本地文件夹，再打开检查。

没有相应设备时可以跳过，不需要为教程购买配件。

**完成标准：** 你知道在哪里选择设备，能用一次实际输入、声音、画面或文件检查是否成功，也能说明当前步骤是否真的需要账户登录。
