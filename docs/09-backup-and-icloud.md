# 09 · 本地备份与可选的 iCloud

[上一章](08-settings-and-privacy.md) · [返回目录](../README.md) · [下一章：常见问题](10-troubleshooting.md)

**本章目标：** 认识本地备份，有设备时验证文件恢复，暂时没有设备时明确自己的备份安排。

本教程默认使用时间机器或独立磁盘副本保留资料。**设置时间机器不需要登录 Apple 账户，也不需要开启 iCloud。** [Apple 时间机器设置说明](https://support.apple.com/zh-cn/104984)

开始前，按自己的设备条件选择路线：

| 你的情况 | 先做什么 |
| --- | --- |
| 有一块可专门用于备份的磁盘 | 按第 1 节设置，再做第 2 节的恢复练习 |
| 已设置时间机器 | 先确认最近备份成功，再做第 2 节 |
| 暂时没有备份设备 | 先读第 3 节，写下备份安排。本次可以跳过设备操作，之后补做 |

第 4、5 节只给已经使用 iCloud，或确实需要它的读者阅读。不用为了本章登录账户，也不用为了继续学习马上购买设备。

## 1. 设置时间机器

准备一块专门用于备份的外置储存设备。Apple 建议其容量至少为 Mac 储存容量的两倍。首次备份可能需要较长时间。

**重要：设置过程中可能要求抹掉磁盘，这会删除磁盘上的现有内容。** 先核对设备名称和容量。有资料的磁盘要先另行保存，不能直接拿来点击抹掉。

1. 将备份设备连接到 Mac。
2. 打开 `系统设置 → 通用 → 时间机器`。
3. 选择“添加备份磁盘”或 `+`，选中准备好的设备。
4. 逐项看清提示，再设置磁盘。需要时启用加密备份，并妥善保存备份密码。
5. 等首次备份结束，查看最近一次成功备份的日期和时间。
6. 日后按自己的使用习惯定期连接备份设备，持续检查最近成功时间。

只有“已添加磁盘”还不够，必须确认备份成功。[Apple 时间机器设置说明](https://support.apple.com/zh-cn/104984)

需要马上备份时，在菜单栏的时间机器菜单选择“立即备份”，并在同一菜单检查进度和最近成功时间。如果没有这个菜单，在系统设置中搜索“时间机器”，找到菜单栏显示选项。其所在分类随版本变化，可能是“控制中心”或“菜单栏”。

## 2. 验证能恢复一份文件

用测试文稿练习，不要先拿唯一的重要原件做实验：

1. 打开访达，选择 `前往 → 个人`，或按 `⇧ ⌘ H`。直接在这个用户文件夹里新建“备份测试”，本练习不用云盘、桌面或文稿文件夹。
2. 用文本编辑新建文稿，写上“A：这是备份前的内容”。将它存到“备份测试”，命名为“恢复练习”，再关闭文稿。
3. 在时间机器设置的“选项”里检查排除列表，确认“备份测试”及其上层文件夹没有被排除。
4. 连接备份设备，选择“立即备份”。等待成功并记下这次备份的时间。
5. 重新打开文稿，改成“B：这是后来修改的内容”，存储并关闭。
6. 在访达打开“备份测试”，用聚焦打开“时间机器”应用。也可以从时间机器菜单选择“浏览时间机器备份”等入口，文字可能因版本而异。
7. 用箭头或时间线找到第 4 步完成的备份，选中“恢复练习”，点“恢复”。文件会回到原来的位置。
8. 若询问替换还是保留两份，选择保留两份。打开恢复出的文稿，确认出现 A 的内容。如果保留了 B，也打开它核对。

只有恢复后打开文件、看到 A 的内容，才算完成验证。如果备份里没有测试文稿，先检查保存位置、排除列表和备份时间，再重新练习。[Apple 从时间机器恢复项目](https://support.apple.com/zh-cn/guide/mac-help/mh11422/mac)

恢复练习完成后，记下成功备份的时间、磁盘名称，以及恢复出来的文件内容。有设备但暂未完成恢复验证时，也把这件事记下来，之后补做。

## 3. 保留习惯比开关更重要

备份应放在独立于这台 Mac 的储存位置。**只复制到这台 Mac 的另一个文件夹，仍可能在电脑损坏或遗失时一起丢失。** 第四章的原件和副本用于练习文件整理，不能替代独立备份。

暂时没有备份设备时，写下准备使用的方式和仍待完成的步骤。如果已有另一块磁盘或另一台电脑，可以先给最重要的资料留下副本，并打开检查。还没有独立副本时，就明确记为“尚未完成独立备份”，不要把计划当成已经备份成功。

磁盘与 Mac 放在同一个包里，可能一起遗失。非常重要的资料，考虑再留一份放在不同位置的副本。加密备份密码也不要只存于需要靠它恢复的那台电脑上。

Mac 内部的本地快照对某些恢复场景有帮助，但与原始磁盘共享风险，不能替代外置备份。[Apple 时间机器与本地快照说明](https://support.apple.com/zh-cn/guide/mac-help/mh35860/mac)

## 4. 按需：同步和备份有什么区别

| 方式 | 主要目的 | 你需要注意什么 |
| --- | --- | --- |
| 时间机器（Time Machine） | 保留 Mac 文件的历史备份 | 需要设置备份目的地并确认备份完成 |
| 手动复制到另一块磁盘 | 留下额外副本 | 需要自己持续更新并检查副本 |
| iCloud 同步（可选） | 让多台设备看到同一份内容 | 修改或删除可能传播到其他设备 |

例如：你在 Mac 的 iCloud 云盘删除一份文稿，其他启用了同一云盘的设备也会失去它。不能因为“文件在云上”，就认为误删时一定有完整、独立的历史副本。[Apple iCloud 删除说明](https://support.apple.com/zh-cn/guide/icloud/mm3b7fcd0c10/icloud)

iCloud 同步不是整台 Mac 的时间机器备份。文件是否真的可恢复，取决于具体服务、保留规则以及你是否另做备份。[Apple Mac 备份入口](https://support.apple.com/zh-cn/mac-backup)

## 5. 按需：已经使用 iCloud 时检查哪些内容

默认不启用 iCloud 云盘、桌面与文稿同步、照片同步或密码与钥匙串同步。若某一项服务确实有用，按[第一章](01-first-steps.md)选择最小登录范围，再检查各项开关，只保留所需服务。[Apple iCloud 设置说明](https://support.apple.com/zh-cn/102314)

已经使用 iCloud 的读者，在访达查看 iCloud 云盘，以及系统设置中 Apple 账户的 iCloud 配置。若启用“桌面与文稿文件夹”同步，桌面和文稿里的内容也参与同步，不只是你手动拖进云盘的文件。

一些云端文件可能只保留下载占位信息，要联网下载才能离线使用。云盘中显示文件名不等于本地已有完整内容。

在访达的 iCloud 云盘中右键点按文件，分清下面几种操作：

| 操作 | 结果 |
| --- | --- |
| 现在下载 | 把云端内容下载到这台 Mac，等待完成后可离线使用 |
| 保留下载（版本提供时） | 要求 Mac 持续保留该项目的下载内容，避免储存空间优化将它移回仅云端状态 |
| 移除下载 | 移除这台 Mac 的下载副本，文件仍留在 iCloud 云盘，下次使用可能需要联网 |
| 移到废纸篓 | 删除这个同步文件，也会影响其他启用同一 iCloud 云盘的设备 |

重要文件出门前先下载并打开检查。需要纳入本地备份时，也要确认原文件已经下载。**下载到本机的同步文件仍会同步修改和删除，并未因此变成独立备份。** [Apple iCloud 文件操作说明](https://support.apple.com/zh-cn/guide/mac-help/mchl1a02d711/mac)、[云端删除说明](https://support.apple.com/zh-cn/guide/icloud/mm3b7fcd0c10/icloud)

想另留一份本地副本时，先下载，使用 `⌘ C` 拷贝，再到不参与同步的目标文件夹按 `⌘ V` 粘贴。直接把文件从 iCloud 云盘移出，会从其他设备的云盘中移除它，不能把这种移动当成“只多存一份”。

准备停用某项同步时，先下载并检查要保留的原文件，留下独立副本，再按官方说明调整开关并核对本机文件位置。不要把删除云端原件当成关闭同步的方法。桌面与文稿停用后的保存位置另见 [Apple 停用说明](https://support.apple.com/zh-cn/126628)。

## 小练习：回答三件事

- [ ] 我的重要文稿保存在哪个位置？已使用云端服务时，再确认它是否正在同步。
- [ ] 已有成功备份时，它是什么时候完成的，放在哪里？还没有时，准备怎么做？
- [ ] 我是否打开过恢复出的测试文件，确认内容正确？尚未验证时，记下待补做的步骤。

**完成标准：** 有备份设备时，能说明备份位置和成功时间，并打开恢复出的测试文稿验证。暂时没有设备时，能说明备份计划和仍待完成的操作。已使用同步服务的读者，还能说明删除文件是否会影响其他设备。
