# 03 · 键盘、触控板与中文输入

[上一章](02-desktop-and-apps.md) · [返回目录](../README.md) · [下一章：访达与文件](04-finder-and-files.md)

**本章目标：** 看懂快捷键，完成点按、右键和滚动，并能输入中文。

## 1. 先认清这些按键

| 教程中的符号 | 按键名称 | 常见位置或含义 |
| --- | --- | --- |
| `⌘` | Command，简称 Cmd | 空格键旁边，常用于日常快捷键 |
| `⌥` | Option，有时标为 Alt | 常用于额外选项 |
| `⌃` | Control，简称 Ctrl | 与 Command 是不同的键 |
| `⇧` | Shift | 输入大写字母或组合快捷键 |
| `Fn` / 地球仪 | 功能键 | 功能取决于键盘与设置 |
| `Return` / `⏎` | 回车 | 确认或换行，在访达中可用于重命名 |
| `Esc` | Escape | 取消部分操作或退出某些状态 |

例如 `⇧ ⌘ 4`：按住 Shift 和 Command，按一下数字 4，再松开各键。数字键使用键盘上方普通数字行即可。

在编辑文本时，MacBook 常见的 Delete 键删除光标前面的字符，相当于许多人熟悉的 Backspace。`Fn Delete` 可以向前删除。在访达里，单按 Delete 与删除文本的行为不同，删除文件见[第四章](04-finder-and-files.md)。[Apple 键盘说明](https://support.apple.com/zh-cn/102650)

## 2. 最先记住的六个组合

| 你要做的事 | 快捷键 |
| --- | --- |
| 拷贝选中的文本或文件 | `⌘ C` |
| 粘贴 | `⌘ V` |
| 撤销刚才的一步 | `⌘ Z` |
| 存储正在编辑的文稿 | `⌘ S` |
| 在运行中的应用之间切换 | `⌘ Tab` |
| 打开聚焦搜索 | `⌘ 空格` |

其他组合可以等需要时查[速查表](shortcuts.md)。应用菜单右侧也会显示它支持的快捷键。

## 3. 触控板先学三件事

| 操作 | 方法 |
| --- | --- |
| 点按 | 用一根手指按下触控板，也可以启用“轻点来点按”后直接轻点 |
| 右键菜单 | 使用配置好的辅助点按手势，常见的是双指点按 |
| 上下滚动 | 两根手指在触控板上滑动 |

在 `系统设置 → 触控板` 查看演示和开关。辅助点按、轻点来点按和滚动方向都可以按习惯调整。普通鼠标也能完成教程中的主要操作。

“自然滚动”是在描述内容与手指移动的方向关系。如果感觉滚动方向不合习惯，在触控板或鼠标设置里调整它，不必硬记一种“正确”方向。

进入调度中心、切换桌面等手势可能设置为三指或四指，先以自己电脑上的演示为准。[Apple 多点触控手势说明](https://support.apple.com/zh-cn/102482)

## 4. 拖移一个窗口

把指针放在窗口顶端可以拖移的空白区域，按住触控板或鼠标按钮，移动到新位置后再松开。不要拖正在编辑的文字区域，否则可能选中文字。

觉得长时间按住不舒服，可以在系统设置内搜索“三指拖移”，按辅助功能的设置启用对应功能。这是可选项，先学会普通拖移即可。

## 5. 添加和切换中文输入

1. 打开 `系统设置 → 键盘`。
2. 在“文字输入”（部分资料称“文本输入”）一栏点“编辑”，查找添加输入法的 `+` 按钮。
3. 选择“简体中文”，再选择“拼音”等你熟悉的输入法，并添加。
4. 在菜单栏输入法菜单中选择刚添加的输入法。
5. 打开文本编辑，输入拼音并选择候选字，检查是否能得到中文。

入口名称可能随版本变化，添加步骤可参照 [Apple 中文输入法说明](https://support.apple.com/zh-cn/guide/chinese-input-method/cim6023ab944/mac)。

默认输入源快捷键常包含 `⌃ 空格`。实际以 `键盘 → 键盘快捷键 → 输入法` 中显示的设置为准。地球仪键的行为也可以在键盘设置中调整。`⌘ 空格` 通常用于聚焦，别把它和输入法切换混淆。[Apple 输入源切换说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp1406/mac)

## 小练习：写两句话

在文本编辑中输入“我开始学习使用 Mac。”和“Hello, Mac.”，练习切换输入法。选中第一句话，拷贝并粘贴一次，再撤销粘贴。

最后打开访达，在一个测试文件上右键点按，看见菜单后按 Esc 取消。

**完成标准：** 你不用猜测就能认出 Command 和 Control，也能输入中英文并打开右键菜单。
