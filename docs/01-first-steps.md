# 01 · 第一次使用 Mac

[返回目录](../README.md) · [下一章：桌面、菜单栏与应用](02-desktop-and-apps.md)

**本章目标：** 能联网、打开系统设置、认清账户，并正确离开或关闭电脑。

已经看见桌面的读者，从第 2 节开始即可。首次学习先完成第 1–5 节和小练习，末尾的更新与 Apple 服务登录内容按需阅读。

## 1. 如果你还在初次设置画面

连接电源，按屏幕提示选择语言、地区和网络。如果暂时不需要迁移旧电脑数据，可以在界面提供相应选项时选择稍后进行。数据迁移不必挤在第一次开机时完成。

创建这台 Mac 的本地用户账户，并为它设置密码。这个密码会用于登录电脑和批准某些系统操作，请先确保自己记得住。不要把练习中随便输入的示例密码当成正式密码。

Apple 账户（也常被叫作“苹果账号”）用于 iCloud、App Store 等服务，与这台电脑的本地账户是两个概念。**本教程默认不登录 Apple 账户。** 看到相应页面时，选择“稍后设置”或界面提供的同类选项，再继续完成设置。基础的网页浏览、文件编辑和时间机器备份可以先用起来。[Apple 初次设置说明](https://support.apple.com/zh-cn/guide/mac-pro/apd831707cb3/mac)

如果画面明确显示“激活锁”，并要求原所有者的账户，先看[第十章的对应说明](10-troubleshooting.md)。这与普通的可选账户登录页不同。

希望自行控制账户和同步设置时，直接在 Mac 上完成设置。“通过 iPhone 或 iPad 设置”可能自动带入原设备的 Apple 账户和 iCloud 设置，不适合本教程默认的使用方式。[Apple 设备辅助设置说明](https://support.apple.com/zh-cn/122216)

公司发的 Mac 请按公司给出的设置要求操作。

## 2. 如果你已经看见桌面

点按屏幕左上角的苹果标志 ``。这里可以打开“系统设置”“关于本机”，也能锁定、重新启动或关闭电脑。

先做下面三件事：

1. 打开 ` → 关于本机`，记下 macOS 版本和芯片或处理器名称，不必记录序列号。
2. 打开 ` → 系统设置 → Wi-Fi`，选择自己的网络并输入网络密码。
3. 在程序坞中点按蓝色指南针图标，打开 Safari 浏览器。在窗口顶部的地址栏输入网址，例如 `https://www.apple.com.cn`，按 Return，确认网页能打开。

如果程序坞里没有 Safari，按住空格键旁的 Command（`⌘`）再按空格，输入“Safari”，打开带指南针图标的应用结果。这个入口叫“聚焦”，下一章会继续练习。

看到 Wi-Fi 图标不一定代表已经能上网。酒店、校园或公共网络可能还需要在浏览器里完成登录。

## 3. 分清三种常见密码

| 名称 | 主要用于什么 | 提示 |
| --- | --- | --- |
| Mac 登录密码 | 登录本地账户、允许部分系统更改 | 系统要求时输入，不是网站密码 |
| Apple 账户密码 | 只在需要登录 Apple 服务时使用 | 可能还需要双重认证验证码，本教程不要求你先准备它 |
| Wi-Fi 密码 | 加入无线网络 | 由网络所有者提供 |

如果你的 Mac 支持触控 ID，可以按提示录入指纹，方便日常解锁。指纹不会取代所有密码验证，重新开机等情况下仍可能需要登录密码。

## 4. 找不到设置时怎么办

打开系统设置，先从窗口左侧的分类列表选择“键盘”“显示器”等项目。本章还没教中文输入，不必为了找设置先输入中文。

设置好[第三章的中文输入](03-keyboard-and-trackpad.md)后，也可以用系统设置的搜索框输入功能名，例如“触控板”或“软件更新”。这样就不用记住所有分类的位置。

文字太小，可以先在“显示器”中查看缩放或文字大小相关选项，也可以在“辅助功能”中查找缩放功能。先让电脑看起来舒服，再开始学习。

## 5. 离开电脑的四种方式

| 你的情况 | 应该怎么做 |
| --- | --- |
| 去倒水，马上回来 | ` → 锁定屏幕`，或按 `⌃ ⌘ Q` |
| 暂时不用电脑 | 选择 ` → 睡眠`。MacBook 通常也可以合上屏幕 |
| 系统或应用出现问题 | 保存工作后，选择 ` → 重新启动` |
| 准备完全关闭电脑 | 保存工作后，选择 ` → 关机` |

锁屏只限制别人进入当前会话。睡眠、关机与锁屏不是同一件事。MacBook 连接外接屏幕和电源时，合上屏幕可能继续工作，因此离开前主动锁屏更可靠。

正常关机用菜单完成。长按电源按钮用于电脑完全没有响应时的应急处理，可能导致未保存内容丢失，详见[排查章节](10-troubleshooting.md)。

## 小练习：建立你的起点

- [ ] 在“关于本机”找到自己的 macOS 版本。
- [ ] 分清 Mac 本地用户账户与 Apple 账户。没有服务需求时，保持后者未登录。
- [ ] 打开系统设置，从左侧分类列表找到“键盘”。
- [ ] 用浏览器成功打开一个网页。
- [ ] 锁定屏幕，再用自己的方式解锁。

**完成标准：** 你知道网络、系统设置和锁屏入口在哪，也知道系统询问的是哪一种密码。

## 6. 按需：检查更新

进入 `系统设置 → 通用 → 软件更新`，先查看是否有适合这台 Mac 的更新。安装前保存工作并备份重要文件。使用笔记本时连接电源，预留安装时间。教程中的学习时间不包括更新等待。[Apple 官方更新说明](https://support.apple.com/zh-cn/108382)

## 7. 按需：只登录需要的 Apple 服务

先明确自己要使用哪项服务，再选择入口：

| 你的需求 | 本教程采用的方式 |
| --- | --- |
| 完成本教程的自带工具练习、编辑本地文稿、做时间机器备份 | 保持 Apple 账户未登录，使用 Mac 本地用户账户 |
| 获取只能从 App Store 下载的应用 | 在 App Store 自身登录，按需获取应用，不为此额外开启 iCloud 同步 |
| 偶尔访问某项 Apple 网页服务 | 如果官方网页版能完成操作，就在网页中登录，用完退出网页 |
| 确实需要 iCloud 的某项同步 | 再考虑在系统设置登录，并检查同步开关，只保留需要的项目 |

App Store 有自己的登录入口，见[安装章节](05-install-and-remove-apps.md)。Apple 也提供[网页登录入口说明](https://support.apple.com/zh-cn/111001)。

在系统设置登录后，iCloud 会自动开启。到 `系统设置 → 你的姓名 → iCloud` 查看全部项目，逐项确认云盘、照片、备忘录、Safari、密码（或“密码与钥匙串”）等服务是否需要。无需同步的项目保持关闭，**不要把登录一个账户理解为同意同步所有资料。** 如果已经在同步，先按[第九章](09-backup-and-icloud.md)核对和保存数据，再调整开关。[Apple iCloud 设置说明](https://support.apple.com/zh-cn/102314)
