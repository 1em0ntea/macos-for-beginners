# 七天练习计划

[返回目录](../README.md)

每天给自己留 20–30 分钟。可以按自己的节奏拆开，不必一定连续七天。初次系统更新与备份的等待时间另算。

练习使用自己的测试文稿，不需要下载第三方软件、购买订阅或向别人发送消息。

## 第 1 天：知道从哪里开始

阅读：[第一次使用 Mac](01-first-steps.md)、[桌面与应用](02-desktop-and-apps.md)。

- [ ] 找到自己的系统版本。
- [ ] 用聚焦打开计算器，计算 `12 × 8`。
- [ ] 用菜单正常退出计算器。
- [ ] 锁屏，再解锁。

**自查：** 指出菜单栏、程序坞和访达，并说明关闭窗口是否一定退出应用。

## 第 2 天：让手和键盘熟悉起来

阅读：[键盘、触控板与中文输入](03-keyboard-and-trackpad.md)。

- [ ] 在文本编辑输入一句中文和一句英文。
- [ ] 拷贝、粘贴一句话，再撤销。
- [ ] 用右键打开菜单，然后取消。
- [ ] 在网页里双指滚动或用鼠标滚动。

**自查：** 不看教程，指出 Command、Option 和 Control 在哪里。

## 第 3 天：让文件有地方住

阅读：[访达与文件](04-finder-and-files.md)。

- [ ] 创建“Mac 入门练习”文件夹及“草稿”“成品”子文件夹。
- [ ] 存储一份文稿，并重新打开检查内容。
- [ ] 把文稿移动到“草稿”，复制一份到“成品”。
- [ ] 对副本重命名，移到废纸篓，再放回原处。

**自查：** 说明复制和移动的区别，以及 Return 在访达中的作用。

## 第 4 天：能同时处理两件事

阅读：[安装与卸载应用](05-install-and-remove-apps.md)、[窗口与多任务](06-windows-and-multitasking.md)。

- [ ] 在“应用程序”里找到文本编辑。
- [ ] 分清 DMG、PKG 与 Windows 安装文件。
- [ ] 将浏览器和文本编辑手动并排。
- [ ] 最小化一个窗口，再找回来。

**自查：** 从程序坞移除图标以后，应用是否被卸载？

## 第 5 天：完成一次小交付

阅读：[完成一次日常工作](07-everyday-work.md)。

- [ ] 写一份三句话的学习记录。
- [ ] 保留编辑原件，并打印存成 PDF。
- [ ] 打开 PDF，检查内容与页数。
- [ ] 截取一部分画面，确认截图没有不需要的私人内容。

**自查：** 不依赖“最近使用”，直接在保存文件夹中找到三个结果。

## 第 6 天：把电脑调成自己的样子

阅读：[设置与隐私](08-settings-and-privacy.md)。

- [ ] 调整一个通知选项，并知道如何改回。
- [ ] 检查声音输入与输出设备。
- [ ] 在系统设置查找麦克风权限。
- [ ] 查看软件更新状态。

**自查：** 某个会议应用无法使用麦克风时，至少知道检查哪两个地方。

## 第 7 天：把成果保留下来

阅读：[备份与 iCloud](09-backup-and-icloud.md)、[常见问题](10-troubleshooting.md)。

- [ ] 确认重要文件是否参与云端同步。
- [ ] 有备份设备时，完成一次备份与测试文件恢复。
- [ ] 暂时没有设备时，写下备份安排，并检查另一个重要文件副本。
- [ ] 按排查章节的表格描述一个真实或假设问题。

**自查：** 说清楚最近备份在哪里，以及误删同步文件可能影响什么。

## 一周后的综合任务

从桌面开始，不翻教程，完成这些操作：

1. 打开文本编辑，写下三个 Mac 使用心得。
2. 存到“Mac 入门练习/成品”，命名为“一周总结”。
3. 生成 PDF，关闭后从访达重新打开确认。
4. 把 PDF 复制到“草稿”，确认原件还在。
5. 截取一个窗口，确认截图保存位置。
6. 正常退出应用，锁定屏幕。

若某一步卡住，只回看对应章节再试一次。能独立完成这些操作，就已经有了日常使用的基础。
