# 七天练习计划

[返回目录](../README.md)

每次给自己留 20–30 分钟，到时间就可以停下。文件整理等较长内容可分两次完成，不必一定连续七天。初次系统更新与备份的等待时间另算。

下面是各章练习的检查清单，具体操作以对应章节为准。遇到不会做的一项，回到那一章跟着步骤做即可，不需要同时重复做两套练习。

练习使用自己的测试文稿，不需要下载第三方软件、购买订阅或向别人发送消息。

## 第 1 天：知道从哪里开始

阅读：[第一次使用 Mac](01-first-steps.md)、[桌面与应用](02-desktop-and-apps.md)。

- [ ] 找到自己的系统版本。
- [ ] 确认使用的是 Mac 本地用户账户。没有 Apple 服务需求时，保持 Apple 账户未登录。
- [ ] 用聚焦输入 `Safari`，打开浏览器。再从访达的 `前往 → 应用程序` 打开计算器，点计算器上的数字、乘号和等号按钮，计算 `12 × 8`，确认结果为 `96`，不必先会输入中文。
- [ ] 用菜单正常退出计算器。
- [ ] 锁屏，再解锁。

**自查：** 指出菜单栏、程序坞和访达，并说明关闭窗口是否一定退出应用。

## 第 2 天：让手和键盘熟悉起来

阅读：[键盘、触控板与中文输入](03-keyboard-and-trackpad.md)。

- [ ] 在文本编辑新建测试文稿，输入一句中文和一句英文。
- [ ] 拖选一句话，拷贝并粘贴到新位置，再撤销粘贴。
- [ ] 选中一个英文单词，替换它，再撤销这次替换。
- [ ] 将插入点移到当前行开头和末尾。
- [ ] 用右键打开菜单，然后取消。
- [ ] 在网页里双指滚动或用鼠标滚动。
- [ ] 完成后关闭测试文稿，这次可以选择“不存储”。

**自查：** 不看教程，指出 Command、Option 和 Control 在哪里，说明输入新文字会放在什么位置。

## 第 3 天：让文件有地方住

阅读：[访达与文件](04-finder-and-files.md)。

- [ ] 创建“Mac 入门练习”文件夹及“草稿”“成品”子文件夹。
- [ ] 将“我的第一份文稿”存到“文稿”文件夹，重新打开检查内容。
- [ ] 把“我的第一份文稿”移动到“草稿”，复制一份到“成品”。
- [ ] 将“成品”中的副本重命名为“已完成的练习”，移到废纸篓，再放回原处。
- [ ] 用访达搜索“已完成的练习”，检查搜索范围和真实路径。
- [ ] 选中“草稿”和“成品”两个文件夹，再取消其中一个的选择。

**自查：** 说明复制和移动的区别，以及 Return 在访达中的作用。知道“替换”同名文件与额外保存副本的区别。

想继续练习，可以另找一天完成第四章第 8–10 节的列表、边栏、另存与旧版本内容，只修改测试文稿。

## 第 4 天：能同时处理两件事

阅读：[安装与卸载应用](05-install-and-remove-apps.md)、[窗口与多任务](06-windows-and-multitasking.md)。

- [ ] 在“应用程序”里找到文本编辑。
- [ ] 分清 DMG、PKG 与 Windows 安装文件。
- [ ] 将浏览器和文本编辑手动并排。
- [ ] 写下三个操作，存到“草稿”，命名为“并排练习”。
- [ ] 最小化一个窗口，再找回来。

**自查：** 从程序坞移除图标以后，应用是否被卸载？

## 第 5 天：完成一次小交付

阅读：[完成一次日常工作](07-everyday-work.md)。

- [ ] 从教程中挑出三个学会的操作，写进“Mac 学习记录”，存到“成品”。
- [ ] 保留“Mac 学习记录”的可编辑文稿，将同一份内容打印存成“Mac 学习记录.pdf”，也放在“成品”。
- [ ] 打开“Mac 学习记录.pdf”，检查内容与页数。
- [ ] 截取一部分画面，确认截图没有不需要的私人内容。
- [ ] 保留原截图，将副本命名为“学习截图”，移动到“成品”，再标记并存储。若临时更改了截图保存选项，练习后改回原选项。

**自查：** 不依赖“最近使用”，直接在“成品”中找到可编辑文稿、PDF 和“学习截图”三个结果。默认应用等按需内容可以以后再看。

## 第 6 天：把电脑调成自己的样子

阅读：[设置与隐私](08-settings-and-privacy.md)。

- [ ] 调整一个通知选项，并知道如何改回。
- [ ] 检查声音输入与输出设备。
- [ ] 在系统设置查找麦克风权限。
- [ ] 查看软件更新状态。

**自查：** 某个会议应用无法使用麦克风时，至少知道检查哪两个地方。

## 第 7 天：把成果保留下来

阅读：[本地备份与可选的 iCloud](09-backup-and-icloud.md)、[常见问题](10-troubleshooting.md)。iCloud 部分可选，不必为了练习登录账户。

- [ ] 记下重要文稿的保存位置。
- [ ] 按自己的设备条件选择一条路线：有备份设备就完成备份与测试文件恢复，没有设备就写下备份安排，并明确记录尚未完成的操作。
- [ ] 已使用云端同步时，再核对文件是否参与同步。没有使用时，不必为了练习登录账户。
- [ ] 按排查章节的表格描述一个真实或假设问题。
- [ ] 找到忘记 Mac 登录密码时的官方恢复入口，不需要实际重设密码。

**自查：** 有设备时，说清楚最近成功备份的位置和时间。打开恢复出的“恢复练习”，确认内容为备份前的 A，再打开另存的“后来修改的内容”，确认内容仍为 B。还没有完成备份时，说清楚准备采用什么方式、哪些操作仍待完成。已使用 iCloud 的读者再检查“移除下载”和“移到废纸篓”的区别。

## 一周后的综合任务

从桌面开始，不翻教程，完成这些操作：

1. 打开文本编辑，写下三个 Mac 使用心得。
2. 存到“文稿”里的“Mac 入门练习”的“成品”文件夹，命名为“一周总结”。
3. 将“一周总结”打印存成“一周总结.pdf”，也保存在“成品”。关闭 PDF 后，从访达重新打开确认内容。
4. 把“成品”中的“一周总结.pdf”复制到“草稿”，打开“草稿”里的 PDF 副本检查内容，再确认“成品”中的可编辑文稿和 PDF 都还在。
5. 截取一个窗口，确认截图保存位置。
6. 正常退出应用，锁定屏幕。

若某一步卡住，只回看对应章节再试一次。能独立完成这些操作，就已经有了日常使用的基础。

## 有设备时再练习

需要连接蓝牙设备、外接屏幕，或者打印、扫描时，再阅读[配件章节](accessories-and-printing.md)并完成与你的设备相符的练习。没有这些设备也能完成上面的七天路线。
