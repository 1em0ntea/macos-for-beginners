# 08 · 设置与隐私

[上一章](07-everyday-work.md) · [返回目录](../README.md) · [下一章：本地备份与可选的 iCloud](09-backup-and-icloud.md)

**本章目标：** 把 Mac 调整到适合自己的状态，并理解常见权限请求。

## 1. 从需求找设置

打开 ` → 系统设置`，用搜索框寻找功能名。下面列出一些常见需求，实际分类可能随版本变化。

| 你的需求 | 可以搜索什么 |
| --- | --- |
| 文字或界面太小 | 显示器、文字大小、缩放 |
| 鼠标或触控板不顺手 | 追踪速度、辅助点按、自然滚动 |
| 通知太多 | 通知、专注模式 |
| 会议听不见或别人听不见你 | 声音、输入、输出、麦克风 |
| 离开后需要及时锁住 | 锁定屏幕、要求密码 |
| 开机自动打开的应用太多 | 登录项 |
| 想查看磁盘占用 | 储存空间 |

一次只改一项，用几分钟再决定是否保留。这样才能知道哪个改动真正解决了问题。

需要连接蓝牙耳机或外接屏幕、了解 MacBook 充电、使用打印机时，按需阅读[配件、充电、打印与扫描](accessories-and-printing.md)。想改默认浏览器或文件打开应用，见[第七章](07-everyday-work.md)。

## 2. 看懂权限请求

系统请求权限时，先看清是哪一个应用，以及你正在做什么。

| 权限 | 合理的常见场景 |
| --- | --- |
| 麦克风 | 语音通话、录音 |
| 摄像头 | 视频会议、拍摄 |
| 屏幕录制 / 屏幕与音频录制 | 屏幕分享、录屏，名称因版本而异 |
| 文件与文件夹 | 访问你选定的文稿或下载等位置 |
| 辅助功能 | 某些自动化、键盘或窗口控制工具 |
| 完全磁盘访问权限 | 部分备份或管理工具，需要更广的文件访问 |

不确定时可以先拒绝，之后到 `系统设置 → 隐私与安全性`（有些页面称“隐私与安全”）查看相应类别。改变权限后，应用可能需要退出并重新打开。

辅助功能和完全磁盘访问权限较广，不是所有软件都需要。软件声称“为了正常使用，请把全部权限打开”，并不足以说明每种权限都合理。

## 3. 维护账户和解锁方式

先管理 Mac 本地用户账户和登录密码。Apple 账户没有实际用途时保持未登录，不需要为了本章新建或登录一个账户。

若确实使用 Apple 账户，再检查双重认证、可信电话号码和账户恢复方式，并按[第一章](01-first-steps.md)控制登录范围与同步项目。重装或更换设备前，确认仍能使用所需账户。

离开电脑时主动锁屏，并在锁定屏幕设置里检查唤醒或关闭屏幕后要求密码的规则。如果其他人经常使用你的电脑，可以给对方建立自己的用户账户，让文件和设置各自分开。

## 4. 找到已保存的网站密码

不必为了记住很多网站密码，把它们写进普通文稿。Mac 提供保存和查看密码的入口：

| 系统版本 | 从哪里查看 |
| --- | --- |
| macOS Sequoia 15 及之后 | 用聚焦打开“密码”应用 |
| macOS Ventura 13、Sonoma 14 | 系统设置中的“密码”，或 `Safari → 设置 → 密码` |

按提示使用触控 ID 或 Mac 登录密码验证，再选择需要查看的账户。如果还没有存过密码，列表为空是正常的。这里保存的是网站和服务的登录信息，不代表你正在修改 Mac 登录密码。[Apple 已存储密码说明](https://support.apple.com/zh-cn/105115)

Safari 在支持的网站中可建议强密码并保存登录信息，之后用于自动填充。接受提示前确认网站和账户。**本机保存密码与 iCloud 跨设备同步是两件事。** 本教程不要求开启“密码与钥匙串”同步，也不要求为它登录 Apple 账户。只有确实需要跨设备使用时，才考虑启用对应服务。[Apple 密码应用说明](https://support.apple.com/zh-cn/120758)、[本机保留密码与钥匙串同步说明](https://support.apple.com/zh-cn/109016)

## 5. 了解文件保险箱

FileVault 在中文界面称为“文件保险箱”。它保护启动磁盘上的数据。搭载 Apple 芯片或 T2 芯片的 Mac 本来就有自动加密，文件保险箱会进一步限制没有登录凭据时的数据访问。

在系统设置里搜索“文件保险箱”，按官方说明查看状态。启用前先理解密码遗忘后的恢复方式。本教程优先使用界面提供的恢复密钥选项，无需为了账户恢复方便而额外登录 Apple 账户。请把密钥准确保存到这台 Mac 之外的安全位置。恢复方式全部丢失时可能无法取回数据。公司或学校的设备可能由管理员管理密钥。[Apple 文件保险箱说明](https://support.apple.com/zh-cn/guide/mac-help/mh11785/mac)

文件保险箱不是备份，电脑损坏或文件误删仍需要[备份方案](09-backup-and-icloud.md)。

已经忘记 Mac 登录密码时，按[第十章的恢复入口](10-troubleshooting.md)检查。文件保险箱恢复密钥与 Apple 账户恢复密钥是两种不同凭据，不要混用。

## 6. 更新与日常维护

通过 `通用 → 软件更新` 查看系统更新，在 App Store 或应用自身的更新入口查看应用更新。大版本升级前，先确认重要工作软件的兼容性，并完成备份。[Apple 更新说明](https://support.apple.com/zh-cn/108382)

想腾出空间，可以在“储存空间”中查看类别，再检查自己认识的下载文件、重复资料和不用的应用。不要为了清理空间随意删除“系统”或资源库中的陌生项目，也不要把每一种问题都交给来历不明的清理工具。

## 小练习：找设置并试一次调整

1. 找到一个自己认识的应用的通知设置，记住原来的开关状态，再按需要改一项。
2. 找到“声音”的输出和输入设置，读出当前设备名称。没有更换设备的需求时，只查看即可。
3. 打开隐私设置，查看一次麦克风权限列表，无需为练习授予新的权限。
4. 回到第一步的通知设置，确认能恢复原来的状态。最后按自己的需要决定是否保留这次调整。

**完成标准：** 你知道在哪里撤回权限，也能把刚才的调整改回去。
